# Nova Hayes Rollout Simulation
An Adobe Captivate-based digital media strategy simulation designed to train emerging strategists through a 31-day artist growth campaign.## The Client — Nova Hayes

| | |
|---|---|
| **Genre** | R&B and Pop · Emerging |
| **Followers** | 14K |
| **Engagement rate** | 8.4% |
| **Primary platform** | TikTok — high saves, strong watch time, low profile visits |
| **Secondary platform** | Instagram — 3K followers, inconsistent posting |
| **The asset** | Strong visual identity and a loyal micro-community |
| **The problem** | 80% of current followers are outside her target demographic |
| **The friction** | Manager pushing daily posting and raw follower growth — misaligned with right-audience strategy |

Nova wants the right fans. Her manager wants more followers. These are two different strategies. The learner has to decide which one they are actually running.


## Project Purpose
Learners assume the role of a digital strategist responsible for guiding emerging artist Nova Hayes through a high-stakes promotional rollout. Each module presents strategic decisions that influence delayed campaign outcomes, training learners in audience growth, platform alignment, content strategy, and performance analysis.

## Core Learning Goals
- Develop strategic decision-making
- Strengthen problem-solving skills
- Simulate real-world campaign pressures
- Build transferable digital media instincts

## Framework
- 6 modules
- 10-slide instructional architecture per module
- Bloom’s Taxonomy progression
- Five-step problem-solving model
- Adobe Captivate simulation build
